# Instructions for agents

You are helping run a community microbe-naming workshop. A research group has sequenced water
(nanopore metagenomes) from a community's lakes, rivers or coast. It has recovered genomes
(MAGs) of bacteria with no names yet. People from the community, often high-school students,
meet those microbes on a website and propose Latin names built from words in their language.

This file is the map. The detail lives in `docs/`:

- [docs/workflow.md](docs/workflow.md): the whole pipeline, from reads to a deployed site, with each script's inputs and outputs
- [docs/new-community.md](docs/new-community.md): the checklist for adding a community (start here for "set up X")
- [docs/ethics-and-data.md](docs/ethics-and-data.md): consent, data sovereignty, licensing, personal data. Read it before publishing anything.
- [docs/deploy.md](docs/deploy.md): hosting, the API key, the daily limit
- [docs/card_game.md](docs/card_game.md): the microbe card game: rules, how each card number is derived, balance tests

## Hard rules

1. **Never put an API key in page code or in the repo.** The browser calls `api/protologue`,
   a PHP proxy that reads the key from `~/.<env_slug>.env` on the host. Locally, `serve.py`
   reads it from `.env` or the same home file. When asked about the env file, list variable
   names only, never values.
2. **Never commit or upload private data.** That covers raw sample metadata (names of people,
   exact coordinates of private sites), sample sheets, licensed dictionaries, `.env` files,
   `*.py` on the web host and `*.bak*` files. `.gitignore` covers the usual names; check
   `git status` before every commit anyway.
3. **The community decides.** Place names, spellings, which words are used, and whether a
   name is submitted are the community's choices. Do not invent words in the community's
   language. Do not "correct" a spelling that came from a community source. Flag doubts
   to the user instead.
4. **Write for the audience.** Page text is for high-school students and community members:
   short sentences, plain words, jargon only inside the 🔍 "more" boxes. Don't mention
   *Candidatus*. A story must not refer to other tabs or to the naming process.
5. **Facts must match the data.** Stories in `narratives.js` cite sites, seasons, abundance
   and same-species checks. Every such claim must agree with `site_data.js`. Rebuild the
   data first, then write or revise text.
6. **Use the group's pipelines and containers.** On the cluster, run tools from the danaSeq
   Apptainer images (`scripts/hpc/env.sh`). Don't install conda environments or one-off
   tools: they cost space and inodes. Inside a container, activate envs with
   `source /opt/conda/etc/profile.d/conda.sh && conda activate /opt/conda/envs/<env>`.
7. **Commit, push, deploy or submit jobs only when asked.**

## Everyday commands

```bash
# rebuild one community's data after analysis outputs change
python3 scripts/build/extract_site_data.py communities/<id>/build_config.json > <inputs_dir>/site_data_dump.txt
python3 scripts/build/build_site_data.py communities/<id>/build_config.json

# assemble and preview (the dictionary is passed in when it is kept outside the repo)
scripts/build/assemble_site.sh <id> /path/to/private/dictionary.js
cd dist/<id> && python3 serve.py 8080 127.0.0.1      # http://127.0.0.1:8080/

# deploy (only when asked)
scripts/build/deploy.sh <id> <ssh-host> <remote-dir> <public-url>
```

## Verifying a change

- After a change to `build_site_data.py`, rebuild an existing community and compare its
  `site_data.js` key by key with the committed one. Only intended keys may change.
- After a change to `index.html`, assemble a site and open every tab (Story, Diversity,
  Distribution, Function, Naming) for at least one marine and one freshwater microbe. Check
  the browser console for errors, and look for `undefined` or `${` in the page text.
- The page must also work with an empty dictionary and with no API key. The draft button then
  explains that it is unavailable.

## Page conventions

- Tabs: Story (default), Diversity, Distribution, Function, Naming. Old hashes
  (`#3/ecology`, `#3/evolution`) still map.
- Data scripts are loaded with `?v=dev`, and `deploy.sh` stamps a timestamp for cache busting.
  Keep that suffix on new `<script>` tags.
- Naming covers genus and species only. GTDB lettered genera (`Thioglobus_A`) count as named.
  Clash checks use `taxon_names.js`.
- Leaflet comes from unpkg. Without it, the maps fall back to the tables.
